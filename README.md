# SafetyBolt coding language

A programming language built around explicit syntax, high performance, very helpful
error messages, and Rust-style memory management. Programs are compiled ahead of time,
either to native code or to a form run by an AOT interpreter.

Early work in progress — nothing here is stable yet.
